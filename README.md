# Система Instagram-каруселей на Claude Code

Claude пишет текст карусели по алгоритму, код верстает слайды в твоих цветах: переписки, шаги, сравнения, настоящие скрины сайтов, пиксельные картинки.

Нужно: Mac и подписка Claude Pro или Max.

## Шаг 1. Поставить Claude Code

Открой «Терминал»: Cmd + Пробел, напиши «Терминал», Enter. Вставь строку и нажми Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Когда закончит — закрой Терминал и открой заново.

## Шаг 2. Запустить Claude в папке для каруселей

Вставь и нажми Enter:

```
mkdir -p ~/Desktop/carousels && cd ~/Desktop/carousels && claude
```

Первый запуск: выбери любую тему оформления → способ входа «Claude account with subscription» → в браузере нажми «Authorize» → вернись в Терминал и на вопрос про папку ответь «Yes».

## Шаг 3. Вставить промпт

Скопируй весь текст ниже, вставь в Claude и нажми Enter. Дальше Claude сделает всё сам: будет спрашивать разрешение на действия (жми «Yes» — Enter) и задавать вопросы про твой блог.

```
Установи мне систему Instagram-каруселей. Я новичок: не работал с терминалом и нейросетями, поэтому всё делай сам и объясняй простыми словами, без терминов.

1. Скачай комплект в текущую папку:
   curl -L https://github.com/artemregi/carousel-kit/archive/refs/heads/main.zip -o kit.zip
   Распакуй так, чтобы содержимое папки carousel-kit-main оказалось прямо здесь (включая скрытую папку .claude), потом удали kit.zip и пустую carousel-kit-main.
   Если здесь уже есть brand.md, config.json или templates/photos/ — это мои данные, их не затирай.
2. Прочитай CLAUDE.md и SETUP.md и выполни SETUP.md по шагам до конца: установка программ, анкета про мой блог, выбор стиля, пиксельные картинки через Gemini, первая карусель.
3. Вопросы задавай по одному-два. Ничего не придумывай за меня: ни фактов, ни цифр, ни цветов.
4. Если что-то сломалось — разберись и почини сам, мне скажи одной фразой, что случилось.
```

## Как пользоваться потом

Каждый раз: открыть Терминал и вставить

```
cd ~/Desktop/carousels && claude
```

Потом пишешь обычным текстом:
- сделай карусель про …
- вот мой пост, упакуй в карусель: …
- слайд 3 слишком плотный / смени хук на второй вариант
- добавь пиксельную картинку: …

Готовые слайды — в папке «carousels» на рабочем столе → output.
