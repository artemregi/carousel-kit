# Система Instagram-каруселей на Claude Code

Claude пишет текст карусели по алгоритму, код верстает слайды в твоих цветах: переписки, шаги, сравнения, настоящие скрины сайтов, пиксельные картинки.

Нужно: компьютер на Mac или Windows и подписка Claude Pro или Max.

## Шаг 1. Поставить Claude Code

Если Claude Code уже стоит (урок 0 или урок 1), пропусти этот шаг.

### Mac

Открой «Терминал»: Cmd + пробел, напиши «Терминал», Enter. Вставь строку и нажми Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Когда закончит – закрой Терминал (Cmd + Q) и открой заново.

### Windows

Открой PowerShell: Пуск, набери PowerShell, открой. Вставь строку и нажми Enter. Если Windows спросит разрешение – «Да».

```
winget install --id Git.Git -e
```

Потом вставь эту строку и нажми Enter:

```
irm https://claude.ai/install.ps1 | iex
```

Когда закончит – закрой PowerShell и открой заново.

## Шаг 2. Запустить Claude в папке для каруселей

### Mac

В Терминале вставь и нажми Enter:

```
mkdir -p ~/Desktop/carousels && cd ~/Desktop/carousels && claude
```

### Windows

В PowerShell вставь и нажми Enter:

```
mkdir ~/Desktop/carousels -Force; cd ~/Desktop/carousels; claude
```

Первый запуск: выбери любую тему оформления → способ входа «Claude account with subscription» → в браузере нажми «Authorize» → вернись в окно и на вопрос про папку стрелкой вниз выбери «Yes» и нажми Enter.

## Шаг 3. Вставить промпт

Скопируй весь текст ниже, вставь в Claude и нажми Enter. Дальше Claude сделает всё сам: будет спрашивать разрешение на действия (жми «Yes» – Enter) и задавать вопросы про твой блог.

```
Установи мне систему Instagram-каруселей. Я новичок: не работал с терминалом и нейросетями, поэтому всё делай сам и объясняй простыми словами, без терминов.

1. Определи систему: macOS или Windows. Скачай https://github.com/artemregi/carousel-kit/archive/refs/heads/main.zip в текущую папку как kit.zip.
   Распакуй так, чтобы содержимое папки carousel-kit-main оказалось прямо здесь (включая скрытую папку .claude), потом удали kit.zip и пустую carousel-kit-main.
   Если здесь уже есть brand.md, config.json или templates/photos/ – это мои данные, их не затирай.
2. Прочитай CLAUDE.md и SETUP.md и выполни SETUP.md по шагам до конца: установка программ, анкета про мой блог, выбор стиля, пиксельные картинки через Gemini, первая карусель. Команды бери для моей системы.
3. Вопросы задавай по одному-два. Ничего не придумывай за меня: ни фактов, ни цифр, ни цветов.
4. Если что-то сломалось – разберись и почини сам, мне скажи одной фразой, что случилось.
```

## Как пользоваться потом

Каждый раз открыть Терминал (Mac) или PowerShell (Windows) и вставить:

Mac:
```
cd ~/Desktop/carousels && claude
```

Windows:
```
cd ~/Desktop/carousels; claude
```

Потом пишешь обычным текстом:
- сделай карусель про …
- вот мой пост, упакуй в карусель: …
- слайд 3 слишком плотный / смени хук на второй вариант
- добавь пиксельную картинку: …

Готовые слайды – в папке «carousels» на рабочем столе → output.

На Windows рабочий стол иногда лежит в OneDrive. Если папки carousels на рабочем столе не видно, скажи Claude «открой папку с каруселями», он покажет, где она.
