# Система Instagram-каруселей на Claude Code

Claude пишет текст карусели по алгоритму (хук, тест свайпа, открытая петля, один призыв), код верстает слайды PNG 1440×1800 в твоих цветах: переписки, шаги, сравнения, настоящие скрины сайтов, пиксельные картинки (100+ готовых, свои — через Gemini).

Установка: открыть Claude Code в пустой папке и попросить «скачай https://github.com/artemregi/carousel-kit и выполни SETUP.md». Дальше Claude всё поставит сам и проведёт анкету.
