# Система Instagram-каруселей

Эта папка — локальная система, которая делает карусели: Claude пишет текст по алгоритму, код верстает PNG 1440×1800.

- `config.json` → `setup_done` не `true` — первым делом выполнить `SETUP.md` (продолжить с шага `setup_step`).
- Любая просьба про карусель — работать по скиллу `.claude/skills/carousel/SKILL.md`.
- Кто автор, аудитория, голос, факты, запреты — `brand.md`. Алгоритм — `knowledge/carousel.md`. Ничего не придумывать сверх этого: нет фактов — спросить.
- Python — `.venv/bin/python` (Windows: `.venv\Scripts\python`), команды — `make.py` (список: `.venv/bin/python make.py`).
- Готовые карусели — `output/<ГГГГ-ММ-ДД>_<тема>/`.
- Пользователь — не программист. Отвечать коротко, простыми словами, без кода в ответах, если он не просит.
- Нельзя: публиковать в Instagram, вводить пароли за пользователя, менять `engine/` без просьбы, использовать фиолетово-синие градиенты, тени и свечение.
